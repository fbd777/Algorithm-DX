# 用「等效选手 Rating」锚定的六档门槛

> 生成：`node scripts/cf-study/anchor-by-player-rating.mjs`（离线，读 `data/cf-study/raw`，窗口 ±500）

规则：`t_rank(q) = 中位用时(题目 Rating = q ｜ 选手赛前 Rating ≈ q × F_rank)`。
`F` 是 maimai 的系数因子；**S 档（F = 1.000）的参照选手正好是 rating ≈ q 的人，也就是 T97 原本的定义**。
参照窗口 ±150，权重按到 target 的距离做高斯衰减（σ = 100）。

「折算到 T97 的窗口」是该档相对 S 快了多少 —— 现行方案这一列从 S+ 到 SSS+ 分别是 1.0 / 2.0 / 2.5 / 3.0 / 3.5%，所以六档挤在半个百分点量级的用时里。
