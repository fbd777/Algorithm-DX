# Algorithm DX · CF 同步扩展

1. 用普通 Edge 打开 edge://extensions，开启开发人员模式。
2. 点击「加载解压缩的扩展」，选择本目录。
3. 打开并登录 Codeforces，刷新 CF 标签页。
4. 在面板的「CF 自建比赛」选择「普通 Edge 扩展」，生成并复制连接码。
5. 点击扩展图标，粘贴连接码并连接；回面板保存配置并同步。

保持 Edge 和 CF 标签页开启。扩展仅读取群组比赛列表、提交记录并发往配对的本机面板，不提取 Cookie、密码或源码。遇到安全验证会暂停，需要手动验证后重连。可在扩展弹窗点「断开」停止连接，面板重新生成连接码可撤销旧连接。使用网页面板启动同步，CLI 同步不支持此方式。

面板地址仅支持本机 localhost / 127.0.0.1。登录授权范围仍由 CF 决定；本扩展不改变群组权限，也不自动解决验证码。

## 0.2.0 读取方式

直接读取 Edge 实际显示的页面，不用 fetch/XHR 再请求 CF HTML。已有匹配页面会直接读取；其他页面在扩展自己的后台标签页打开并翻页，不改变原有标签页。若出现验证，点击扩展「打开读取页面」手动处理后重连；扩展不会自动操作验证码。页面时间在加载初期记录原始值，无法确定原始时间时拒绝写入而不猜测时区。更新后请重新加载扩展，并刷新已有 CF 标签页一次。
