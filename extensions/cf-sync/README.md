# Algorithm DX · CF 同步扩展

1. 用普通 Edge 打开 edge://extensions，开启开发人员模式。
2. 点击「加载解压缩的扩展」，选择本目录。
3. 打开并登录 Codeforces，刷新 CF 标签页。
4. 在面板的「CF 自建比赛」选择「普通 Edge 扩展」，生成并复制连接码。
5. 点击扩展图标，粘贴连接码并连接。回面板确认「扩展已连接」，点击「保存并获取群组历史」。
6. 等同步结束后查看 AC 记录；填写用时后可在练习历史中查看。连接成功和页面读取成功都不等于记录已入库；同步结果才是最终结果。

保持 Edge 和 CF 标签页开启。扩展仅读取群组比赛列表、提交记录并发往配对的本机面板，不提取 Cookie、密码或源码。遇到安全验证会停止本次读取；手动完成验证后，可在面板重试。可在扩展弹窗点「断开」停止连接，面板重新生成连接码可撤销旧连接。使用网页面板启动同步，CLI 同步不支持此方式。

面板地址仅支持本机 localhost / 127.0.0.1。登录授权范围仍由 CF 决定；本扩展不改变群组权限，也不自动解决验证码。

## 0.2.0 读取方式

直接读取 Edge 实际显示的页面，不用 fetch/XHR 再请求 CF HTML。已有匹配页面会直接读取；其他页面在扩展自己的后台标签页打开并翻页，不改变原有标签页。若出现验证，点击扩展「打开读取页面」手动处理后重连；扩展不会自动操作验证码。页面时间在加载初期记录原始值，无法确定原始时间时拒绝写入而不猜测时区。更新后请重新加载扩展，并刷新已有 CF 标签页一次。

## 0.3.0 连接与排查

- 扩展详情中的网站访问权限需允许在 `https://codeforces.com/*` 上运行；只允许点击时访问可能导致自动打开的新标签页无法读取。
- 首次安装或更新扩展后，在 `edge://extensions` 点击重新加载，再刷新一个已登录的 CF 标签页并连接。平时无需反复生成连接码。
- 普通 Edge 的任意已登录 CF 页面都可作为连接入口，不要求先进入 Group；登录账号必须有目标群组的访问权限。
- 群组配置读取群组 STATUS，按账号和比赛归类；不会将其他人的提交记到自己名下。
- 面板会显示连接状态、当前页面和最近错误。读取失败后连接保留，可直接从面板重试；不会自动完成安全验证。
- 自建题没有官方难度时仍进入提交和 AC 记录，不能凭空生成难度或保证进入 B50。

## 0.3.1 单场失败恢复

读取标签页持续停留在旧比赛时，扩展会新建一次读取页再试。个人提交页无法打开时，面板会尝试 STATUS 并按用户名筛选。单场异常不会丢弃已读取的其他比赛记录；面板会提示“群组未完成”，历史回补保留未完成场次的进度。部分更新不表示整个群组已经完整同步。

## 0.4.0 比赛默认用时

群组比赛列表中的开赛时间和时长随记录一起保存，供原有比赛估算规则使用。第一道 AC 从开赛计时，后续从前一道 AC 计时；交叉提交或赛后 AC 等不符合现有规则的情况不自动估算。更新扩展后刷新群组列表再同步即可。已配置 API 授权的用户也可通过官方群组比赛列表补齐时间。估算值仍需在面板点击填入，不会自动替你创建练习记录；没有官方难度不影响显示估算用时。
